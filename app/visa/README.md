# Visa Payment Terminal Enrollment

This module is a draft validator only.

Before enabling requests:
1. Obtain the exact enrollment endpoint from Visa documentation.
2. Confirm the API is added to the correct Visa Developer project.
3. Obtain the required Visa certificates and public key references.
4. Follow the official authentication and signing requirements.
5. Use authorized test terminal data in Certification first.

Never put private keys, consumer data, or credentials in source control.
Enrollment does not confirm a bank balance or settle a payment.
